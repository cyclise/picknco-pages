Chez Pick'n Co, nous nous engageons à protéger votre vie privée et vos données personnelles conformément au Règlement Général sur la Protection des Données (RGPD - UE 2016/679). Cette politique explique de manière claire et transparente comment nous collectons, utilisons, stockons et protégeons vos informations personnelles.

Responsable du traitement

Nom : Pick'n Co
Type : Application mobile
Contact DPO : pickn.co.help.center@gmail.com

En tant que responsable du traitement, Pick'n Co détermine les finalités et les moyens du traitement de vos données personnelles et s'engage à respecter le RGPD.

1. Données collectées et bases légales

Données obligatoires (nécessaires à l'utilisation du service) :

  • Pseudo : Identification dans l'application
  • Email : Authentification et communication
  • Code d'invitation : Gestion du réseau social

Base légale : Exécution du contrat (art. 6.1.b RGPD)

Données facultatives (avec votre consentement) :

  • Localisation : Affichage sur carte (désactivable)
  • Notifications push : Alertes d'événements (désactivable)
  • Données d'usage : Statistiques anonymes (désactivable)

Base légale : Consentement (art. 6.1.a RGPD) - révocable à tout moment

Données techniques automatiques :

  • Informations appareil : Type, version OS, modèle
  • Données de connexion : Date, heure, durée d'utilisation
  • Logs techniques : Erreurs, crashs pour débogage

Base légale : Intérêt légitime (art. 6.1.f RGPD) - maintenance et sécurité

Données de modération :

  • Signalements : Type de contenu signalé, catégorie, raison, date
  • Utilisateurs bloqués : Liste des utilisateurs que vous avez bloqués, date de blocage

Base légale : Intérêt légitime (art. 6.1.f RGPD) - sécurité et modération de la communauté

2. Gestion de vos consentements

Vous pouvez gérer vos consentements à tout moment directement dans l'application :

  • Localisation : Paramètres → Gestion des données → Localisation
  • Notifications : Paramètres → Notifications
  • Statistiques : Paramètres → Gestion des données → Statistiques d'usage

Le retrait de votre consentement n'affecte pas la licéité du traitement fondé sur le consentement effectué avant le retrait.

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Gestion de votre compte : Authentification, profil, préférences
  • Organisation d'événements : Création, participation, coordination
  • Communication : Messagerie instantanée entre participants
  • Réseau social : Gestion d'amis, invitations, notifications
  • Localisation : Affichage des événements sur carte (avec votre consentement)
  • Sécurité : Prévention des abus, modération
  • Amélioration du service : Statistiques anonymes (avec votre consentement)

Nous ne vendons jamais vos données à des tiers.

4. Destinataires des données

Autres utilisateurs de Pick'n Co :

  • Votre pseudo et avatar (visible par tous les participants de vos événements)
  • Vos messages dans les chats d'événements
  • Les événements que vous créez ou rejoignez

Sous-traitants techniques (hébergement et services) :

  • Supabase : Hébergement base de données et authentification (Serveurs AWS Europe - Paris, France)
  • Google Maps Platform : Affichage de cartes et géolocalisation (États-Unis, protégé par Clauses Contractuelles Types)
  • Expo : Notifications push (États-Unis, protégé par Clauses Contractuelles Types)

Tous nos sous-traitants sont conformes au RGPD et garantissent un niveau de protection équivalent à celui de l'Union Européenne.

5. Transferts hors de l'Union Européenne

Certaines données peuvent être transférées vers des pays hors UE :

  • Google Maps (États-Unis) : Protégé par les Clauses Contractuelles Types (CCT) approuvées par la Commission Européenne
  • Expo Push Notifications (États-Unis) : Protégé par les Clauses Contractuelles Types (CCT)
  • Supabase : AUCUN transfert hors UE - Données hébergées exclusivement en Europe (Paris, France)

Ces transferts sont encadrés par des garanties appropriées conformément à l'article 46 du RGPD.

6. Durée de conservation

  • Compte actif : Tant que votre compte existe
  • Après suppression du compte : Effacement immédiat, 30 jours maximum pour les sauvegardes techniques
  • Événements terminés : Suppression automatique 7 jours après la date de fin
  • Messages de chat : Supprimés avec l'événement associé
  • Logs techniques : 90 jours maximum

7. Sécurité des données

Nous mettons en place des mesures techniques et organisationnelles appropriées :

  • Chiffrement : HTTPS pour toutes les communications, chiffrement au repos dans Supabase
  • Authentification sécurisée : Mots de passe hashés avec bcrypt, tokens chiffrés
  • Contrôle d'accès : Row Level Security (RLS) sur la base de données
  • Sauvegardes : Sauvegardes régulières chiffrées
  • Surveillance : Monitoring et détection d'anomalies

8. Vos droits RGPD

Conformément au RGPD, vous disposez des droits suivants :

Droit d'accès (art. 15)

Vous pouvez accéder à toutes vos données depuis l'application : Paramètres → Gestion des données → Consulter mes données

Droit de rectification (art. 16)

Vous pouvez modifier vos informations : Paramètres → Profil

Droit à l'effacement (art. 17)

Vous pouvez supprimer votre compte et toutes vos données : Paramètres → Gestion des données → Supprimer mon compte

Droit à la portabilité (art. 20)

Vous pouvez exporter vos données au format JSON : Paramètres → Gestion des données → Exporter mes données

Droit d'opposition (art. 21)

Vous pouvez vous opposer au traitement de vos données à tout moment en supprimant votre compte.

Droit de limitation (art. 18)

Vous pouvez demander la limitation du traitement en nous contactant.

Exercer vos droits

Pour toute demande concernant vos droits RGPD :

Email : pickn.co.help.center@gmail.com

Délai de réponse : 1 mois maximum (article 12.3 RGPD)

9. Droit de réclamation

10. Cookies et technologies similaires

Pick'n Co n'utilise PAS de cookies publicitaires ou de tracking. Nous utilisons uniquement :

  • Stockage local technique : Pour sauvegarder vos préférences (thème, langue) et maintenir votre session connectée
  • Tokens d'authentification : Stockés de manière sécurisée et chiffrée sur votre appareil

Ces données techniques sont nécessaires au fonctionnement de l'application et ne sont pas partagées avec des tiers à des fins publicitaires.

11. Modifications de cette politique

Nous pouvons modifier cette politique de confidentialité pour refléter les changements dans nos pratiques ou pour des raisons légales. En cas de modification substantielle :

  • Nous mettrons à jour la date de "Dernière mise à jour" en haut de cette page
  • Nous vous notifierons via l'application
  • Nous vous demanderons votre consentement si nécessaire

Nous vous encourageons à consulter régulièrement cette politique pour rester informé(e).

Email : pickn.co.help.center@gmail.com
Délai de réponse : 1 mois maximum (article 12.3 RGPD)
